# untold design context

The source of truth is the approved identity in ../untold/design-tokens.json.

The studio designs and develops websites. Use Ink #0B0D0C, Paper #F3F2EC,
Volt #D7FF3F, Outfit and IBM Plex Mono. Preserve the original interrupted-U mark.

The page uses editorial type, an original fixed 3D extrusion, open service
rows, a project empty state, a typographic process and a large wordmark close.
Native dialogs handle the menu and briefing. Internal pages cover Estúdio,
Projetos, Processo and Contato, sharing the home navigation and footer.

Keep responsive behavior, keyboard access, reduced motion and the original
vector poster fallbacks. The sculpture is static: no automatic rotation,
pointer interaction or pause buttons. Align service titles and descriptions
with the corresponding columns in the studio heading. Never invent clients, metrics,
awards, contact destinations or successful message delivery.

21st design context was initialized and catalog search was attempted. The
catalog required authentication, so no third-party component code was retrieved.
The implementation continues the supplied identity with original components.
